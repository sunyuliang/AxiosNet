遥测（旁路 · 只读）

请求级：IsEnabled → EnterRequest → StartRequest → SetRequestBodySize → RequestSucceeded / Failed → ExitRequest → Stop

事件级：CacheHit / Miss / Stored / Revalidated、Retry、RetryBudgetRefused、GateRejected、AttemptStop / Failed、Pool / Lease 计数

IsEnabled 只管请求级；事件类不看这个开关，要全关只能用 AxiosTelemetrySink.Off。

AxiosTelemetry.Sink 的落点

  • 库内所有调用点走 Dispatch（内部的 GuardedTelemetrySink 护栏），不是直接读 Sink
  • 默认 BuiltInTelemetrySink → ActivitySource / Meter / DiagnosticListener（名字都是 AxiosNet）
  • 自定义：派生 AxiosTelemetrySink（全空基类），只覆写关心的方法
  • 换 Sink 是整套替换，内置三路随之停用，不叠加

三个例外，不是漏画

  1. 短路与缓存命中：在遥测起点之前返回，不产生 span，只发 CacheHit 这类事件
  2. 401 重放：门面层再跑一条完整管线，请求拦截器会重跑；不属于同一条管线内的一次尝试
  3. 连接租约：取连接在终端第 03 步；流式成功时随正文转交 StreamOwner，由流的 Dispose 释放
